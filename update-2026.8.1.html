📌 ملخص الإصدار

الإصدار 2026.8.1 هو إصدار شهري جديد من OpenClaw يركّز على دعم GPT-5.6 Ultra مع تبديل Runtime ديناميكي بين Sol و Terra و Luna، إضافة مساعد Logbook الجديد لتوثيق العمل، إعادة هيكلة شاملة لـ Control UI، إضافة أداة tts.speak للمشغل، وتحسينات عميقة على القنوات (Slack، Discord، WhatsApp، Microsoft Teams، iMessage، Feishu، Tlon، IRC) وإصلاحات ضخمة في Codex و Codex runtime.

🎯 أبرز المميزات الجديدة

Models

GPT-5.6 Ultra + Runtime Switching (Sol / Terra / Luna)

دعم النماذج الجديدة عبر OpenClaw و Codex engines، مع إبقاء اختيار النموذج و الـ runtime و الـ thinking ذرّي عند استخدام /model أو fallback، إضافة تغطية live matrix لكلا الـ harness.

Meta Provider

دعم muse-spark-1.1 الرسمي

دعم Responses API streaming، استدعاء الأدوات، إعادة reasoning مشفّر، onboarding، وتوزيع منفصل عبر npm و ClawHub.

Plugin جديد

Logbook — يوميات العمل التلقائية

إضافة plugin جديد (معطّل افتراضياً) يحوّل snapshots شاشة العقدة المقترنة إلى timeline خاص، standup يومي، وأسئلة وأجوبة مبنية على الـ timeline — يُعرض في تبويب جديد في Control UI.

Control UI

إعادة هيكلة كبيرة لواجهة التحكم

شريط جانبي مخصّص مع pinned destinations، نقل Settings للفوتر، إظهار تفاصيل token/context/model لكل رسالة، عرض حالة GitHub issues/PRs على hover، تخصيص الجلسات الأخيرة، وتحسينات ضخمة على الـ history rendering.

Cron

اختيار النموذج في Cron Jobs

اختيار agent-turn model عند إنشاء cron من Control UI Quick Create، وعرض النموذج المكوّن أو الافتراضي في صفوف التفاصيل.

Android

اختيار الـ Agent مباشرة من شاشة المحادثة

تبديل الـ agent النشط مباشرة من شاشة المحادثة، مع الإبقاء على نفس الـ session في Talk mode و home canvas.

iOS

دعم Offline Chat

عرض الجلسات و transcripts الأخيرة من cache محدود لكل gateway، تعطيل الإرسال offline، وتنظيف cache عند reset للاقتران.

Gateway

tts.speak RPC + Gateway Host Status

إضافة RPC جديد لتحويل النص إلى كلام للعمّال البعيدة، وعرض تفاصيل host الـ gateway المتصل (OS، runtime، uptime، CPU، RAM، disk) في Settings.

Slack

مؤشرات تقدم Slack أصلية

استخدام native assistant thread status و rotating loading messages بشكل افتراضي، مع تحكم جديد عبر messages.statusReactions.enabled.

Android UI

تلوين كود الموبايل

تلوين fenced code blocks لـ Kotlin و Swift و TypeScript و JavaScript و Python و Bash و JSON مع ألوان موضعية آمنة، دون التأثير على النصوص غير المعروفة.

🔧 إصلاحات بارزة

Setup

Crabbox Hydration على Cloud Sandboxes

إصلاح فشل Hydration على sandboxes غير المميزة عبر السقوط إلى user-writable pnpm store مع الحفاظ على hardlink import mode بعد الـ hydration، وإجبار Docker كق capability صريح بدلاً من متطلب ضمني.

Channel SDK

Plugin Ingress Monitor موحّد

إضافة SDK monitor موحّد لـ admission متينة، polling، pruning، claim identity validation، adoption handoff، و shutdown — تم ترحيل IRC و Synology Chat و Google Chat إلى الـ lifecycle الموحّد.

Codex

Codex runtime switching وإصلاحات app-server

قبول Codex runtime لـ codex/* و openai/* مع رفض غير المدعوم، ترقية إلى app-server 0.142، استرجاع spawn_agent المؤجل عبر tool_search، انتظار command-line من app-server قبل الفحص.

WhatsApp

إصلاح استعادة WhatsApp

إصلاح recovery لـ malformed auth state من نسخة احتياطية سليمة، الحفاظ على quote metadata للرسائل المرسلة من البوت، استقبال رسائل Baileys المفقودة، وإيقاف restart loops بعد logged-out.

Discord

إصلاحات Discord Voice و Echo Suppression

عزل اتصالات Discord voice بـ Discord account، إصلاح Discord error 10065 كحالة disconnected عادية، إرسال completion replies كرسائل جديدة، وإيقاف webhook copies من إعادة الدخول إلى agents.

Microsoft Teams

فك تشفير HTML entities + حدود الاستجابة

فك تشفير HTML5 entities بشكل ثابت في الرسائل المقتبسة، تحديد حجم قراءة JSON من Graph لمنع استنزاف الذاكرة، وفك تشفير attachment metadata.

Session Settings

استعادة دمج first writes المتزامنة

إصلاح regression في lock ordering كان يمنع دمج إعدادات global و project، دون أي تأثير جانبي على missing-settings reads.

Secrets

SecretRef model credentials

الإبقاء على provider secrets خلف process-local sentinels عبر auth storage و stream setup، حقن النص الصريح فقط عند الـ network boundary مع redaction كامل في الـ logs.

Control UI

تسريع startup وتاريخ Control UI

تقليل construction لمخططات التكوين، تخطّي مقارنة النصوص المكررة للرسائل المختلفة، استرداد stale bundle pages بعد restart، وعرض banner واضح عند update أثناء restart.

🚀 طريقة التحديث

  1. تحديث OpenClaw عالمياً:
npm install -g openclaw@latest
  1. أو تشغيل wizard التحديث المدمج:
openclaw update
  1. إعادة تشغيل Gateway:
openclaw gateway restart
  1. التحقق من الإصدار الجديد:
openclaw --version

💡 ملاحظة: إذا كنت تستخدم update --no-restart، تأكد من وجود offline managed Gateway قبل updater-owned repair، وإلا ستتم إعادة التشغيل بواسطة الـ parent.

⚠️ تنبيهات قبل التحديث

  • الإصدار الجديد يستخدم OpenClaw 2026.8.1 ويتطلب Node متوافق (يُفضّل 22 LTS أو 24+).
  • تأكد من عمل نسخة احتياطية للإعدادات قبل التحديث:
cp -r ~/.openclaw ~/.openclaw.backup-$(date +%F)
  • إذا كنت تستخدم Codex، تأكد من أن app-server >= 0.142.
  • إذا كنت تستخدم LM Studio embeddings، الحد الأقصى للـ context window سيُحترم لمنع OOM.
