🛠️ إزاي تحدّث

خطوات التحديث من الإصدار الحالي 2026.5.20 إلى 2026.9.6:

# 1. اعمل باك أب للـ workspace قبل أي تحديث cp -r ~/workspace ~/workspace.backup.$(date +%Y%m%d) # 2. شوف الـ gateway status الأول openclaw gateway status # 3. اعمل restart بعد ما تحدّث openclaw gateway restart # 4. لو فيه مشكلة، ارجع للـ extended-stable npm install -g openclaw@2026.7.35 # 5. تحقق من الإصدار بعد التحديث openclaw --version
💡 نصيحة: لو مش متأكد، حدّث لـ 2026.7.35 (extended-stable) — أكثر استقراراً للـ production

⚠️ ملاحظات مهمة قبل التحديث

  • خد باك أب لـ ~/workspace قبل التحديث
  • تأكد إن الـ gateway مش شغال في مهام حساسة وقت التحديث
  • راجع الـ changelog الرسمي على npm للحصول على تفاصيل التغييرات الكاسرة
  • لو عندك skills أو plugins مخصصة، تأكد إنها متوافقة مع الإصدار الجديد
  • الترقية من 5.20 لـ 9.6 قفزت 4 إصدانات رئيسية — خلي بالك من breaking changes
