⚡ أبرز المميزات (Highlights)

  • أمان تحديثات أكثر أماناً: تجربة تغييرات الـ Core والإضافات في حالة مرشحة معزولة قبل التفعيل، دعم ترحيلات 2026.9.2 المؤهلة، واستعادة سجلات التحديثات المهجورة دون إيقاف Gateway الصحي.
  • أداء الحفاظ على ذاكرة Prompt Cache: تقليل الأعمال غير الضرورية أثناء تحديث الجلسات الباردة والبحث في الذاكرة، وإعادة استخدام بناءات الـ Worker بين الجلسات.
  • Skill Workshop ورشة المهارات المحسنة: الاحتفاظ بالمهارات في مجموعة دائمة مملوكة للوكيل عبر workspaces، مقارنة تعليمات المهارات الكاملة، وإيقاف المسودات المفقودة بأمان من خلال Doctor.
  • تصفح تبويبات المتصفح: مشاهدة صفحات الوكيل تتحدث وفتح روابط خارجية في تبويبات Mac الأصلية تبقى مع نافذتها عند تبديل المحادثات.
  • نماذج إدارة حسابات المزودين: إدارة الحسابات المتصلة وأولويات الحسابات المدعومة مباشرة من إعدادات Models.
  • مشاركة مشاركة المحادثات المحددة: نشر عرض قابل للإلغاء وقراءة فقط للنصوص الحالية والمستقبلية لجلسة معينة، يمكن لأي شخص لديه الرابط العام الوصول إليها.
  • اجتماعات مكتبة اجتماعات قابلة للبحث: تصفح الملاحظات المحفوظة، البحث في النصوص الكاملة، تنزيل أرشيفات Markdown أو JSONL كاملة، وإدارة مصادر الالتقاط من Control UI.
  • فريق تقارير نشاط الفريق (اختيارية): تثبيت وتفعيل Team Reports لتصفح نشاط GitHub المصادق ومناقشات Discord المُكوّنة صراحةً، مع سجل وملخصات نموذج اختيارية.

⚠️ تغييرات كاسرة (Breaking Changes)

🚨 Node Runtime: يتطلب Node 24.16.0 أو أحدث على 24.x، أو Node 26.1.0 أو أحدث — يُوصى بـ Node 26. يجب ترقية Node قبل OpenClaw لمنع قطع نص SQLite. لم تعد Node 22 و Node 25 وبنيات 24.x/26.x الأقدم مدعومة.
  • SDK سياسة التنفيذ: نقل أدوات exec-mode و comparator المُهمَلة من infra-runtime إلى execPolicy على openclaw/plugin-sdk/agent-harness-runtime. استخدم resolveExecModePolicy واختر الحقول المطلوبة من المستدعي.
  • أذونات exec: نقل ومزامنة قائمة approveMainChannel وأذونات exec وinclude بين approve.json و config. اقرأ الـ includes ولا تندمج حرفياً لتجنب الإحلال غير المقصود.
  • Plugin host compatibility: يُحتفظ بدعم Discord و llama.cpp و Voice Call لإصدار 2026.9.2 من خلال الـ WebSocket البديل — لا يُستعاد تصدير SDK المتقاعد عمداً.

🔧 أهم التغييرات (Changes)

🔐 الأمان والتحديثات

  • Updates استعادة سجلات التحديثات المهجورة دون إيقاف Gateway الصحي.
  • Updates التحقق من ملكية الخدمة، الصحة المستقرة، تطابق الإصدار وهوية البناء، تفعيل الإضافات، جاهزية القنوات و HTTP دون استدعاء نموذج.
  • Updates rehearsal التغييرات في نسخ مرشحة معزولة، بما في ذلك التبعيات المرتبطة والمُعلّقة في workspace.
  • Audit الحفاظ على بيانات إعادة التحرير الميداني الحساسة و URL-redaction في استجابات التكوين.

🏗️ Skill Workshop

  • Reviews مقارنة تعليمات المهارات الكاملة مع التغييرات المضمنة، والتمييز بين المهارات المثبتة وسجل الاقتراحات.
  • Recovery إيقاف اقتراحات المسودات المفقودة من خلال Doctor مع الحفاظ على المهارات المثبتة.
  • Learning استعادة الذاكرة وتحديث المهارات بعد إرهاق المراقب، والحفاظ على المهام المحددة.

💬 الجلسات والمحادثات

  • Sessions الاحتفاظ بعمل نشط، مدخلات في الطابور، ملكية سجل التحديث، وتقدم الطرفيات عبر التحديثات الطويلة.
  • Sessions دعم ترقيات npm من 2026.9.1 واستئناف التزويد السحابي عبر إعادة تشغيل Gateway.
  • Retention أرشفة المحادثات القديمة بهوياتها وأجيال النص سليمة، ورفع الحد الافتراضي للجلسات النشطة إلى 5,000.
  • Quality الحفاظ على بطاقات المهام السابقة أثناء إعادة تعيين كاملة ومنع كتابة قديمة في الرحلة من استعادتها.

📱 Android و iOS و Mac

  • Android إبقاء عناصر التحكم في Send و Talk قابلة للاستخدام أثناء التشغيل النشط، استعادة تحديثات Gateway الثانوية، تقليل المحاولات لـ Gateways غير القابلة للوصول.
  • Android منع اتصال المشغل المتأخر من استبدال رمز جهاز أحدث صدر أثناء تسليم Android bootstrap.
  • Voice تضمين voice في الإعداد العادي لـ Apple Watch.
  • Mac توفير تغليف AppImage Linux ARM64 وبطاقات Gateway الحية مع فتح نافذة مباشرة في قائمة macOS Gateways.

🔌 Channels و Provider

  • Teams الحفاظ على التنسيق والإشارات في ردود Microsoft Teams المحررة والنهائية.
  • Telegram عرض حالة الـ compaction في معاينات الإجابة المفعلة.
  • Bun استخدام تطبيقات WebSocket المُعلنة تحت Bun عبر Discord و Mattermost و Signal و Gateway و workers ومكالمات الصوت ومسارات المزود.
  • CLI عرض وكلاء CLI القادرين على الإنشاء في منتقي نموذج الجلسة الجديدة دون opt-in منفصل.

🛠️ Gateway و Service

  • Gateway إعداد Gateway secret واحد في Control UI، وإنشاء Gateway token محلي افتراضياً.
  • Browser طلب إضافة Chrome الرسمية من متجر Chrome من خلال إعدادات Mac المحلية.
  • CLI تجميع openclaw-mac لفحص وتكوين اتصالات Gateway للـ Mac من Terminal.
  • Recovery استعادة التركيبات المؤهلة التي تم التحقق منها بعد فشل التفعيل أو انتقالات الخدمة.
  • Diagnostics الإبلاغ عن أوقات مرحلة cloud bootstrap لتحديد تأخيرات التزويد.

🐛 إصلاحات مهمة (Key Fixes)

  • 🔧 الإعدادات المؤلفة: الحفاظ على الإعدادات المُؤلفة ومراجع البيئة والسر من خلال الإعداد والتحديثات وحفظ الإعدادات وترحيلات Doctor.
  • 🔧 Gateway maintenance: إبقاء أعطال إعادة التشغيل العادية قابلة للاسترداد في العملية الأمامية، وإيقاف حلقات إعادة التشغيل عندما تمنع الترحيلات بدء التشغيل.
  • 🔧 تحديث الإضافات: تشغيل صيانة ما بعد التحديث من خلال CLI المفعل، ومحاذاة الإضافات الرسمية المرتبطة بالإصدار.
  • 🔧 استرجاع الخدمة: الحفاظ على أهداف الخدمة والمصادقة أثناء الحالة والإصلاح، وتحمل خطوات ساعة systemd.
  • 🔧 MCP session continuity: إبقاء خوادم MCP المملوكة للجلسة حية بين المنعطفات وفترات الهدوء مع التنظيف عند Stop وإعادة التعيين.
  • 🔧 متانة المحادثة: نشر إعادة كتابة النص ذرياً حتى لا تكشف الانقطاعات تاريخاً جزئياً.
  • 🔧 استمرارية الكود: الحفاظ على نتائج الأدوات المهيكلة الكاملة أو إرجاع خطأ resource-limit قابل للالتقاط، والاحتفاظ بإعلانات MCP ونتائج البحث.
  • 🔧 فهرسة الذاكرة: إبقاء البحث بالكلمات الرئيسية متاحاً عندما يتعذر بدء embeddings اختيارية، واستخدام فحص دفعي قابل للإلغاء.
  • 🔧 استمرار Cache: الحفاظ على prefix المحادثة والأدوات الدافئة عبر حلقات الأدوات وأنشطة الخلفية وموافقات Windows.
  • 🔧 HTTPS محمي: تجديد شهادات HTTPS leaf مع الحفاظ على استقرار سلسلة ثقة عملية Gateway.
  • 🔧 Prometheus: طلب إذن قراءة المشغل الفعال قبل تقديم مقاييس Prometheus.
  • 🔧 إعداد الاعتماد: السماح بتسليمات طلبات تسجيل الدخول وأكواد الإقران في المحادثات الخاصة.
  • 🔧 WebSocket Bun: استخدام تطبيقات WebSocket المُعلنة تحت Bun عبر جميع القنوات.

🚀 تعليمات التحديث

📋 المتطلبات الأساسية: قبل التحديث إلى 2026.9.3، يجب ترقية Node.js إلى الإصدار 24.16.0+ (أو 26.1.0+ المُوصى به). الإصدارات الأقدم لم تعد مدعومة.

📌 خطوات التحديث على السيرفر

1 نسخة احتياطية
cp -r ~/.openclaw ~/.openclaw.backup-$(date +%Y%m%d)
2 ترقية Node.js إلى 24.16.0+ (مهم جداً)
# باستخدام nvm nvm install 24 nvm use 24 node --version # يجب أن يكون v24.16.0 أو أحدث
3 تحديث OpenClaw
npm install -g openclaw@2026.9.3 # أو npm update -g openclaw
4 إعادة تشغيل Gateway
openclaw gateway restart # أو (Docker) docker compose restart openclaw
5 التحقق من التحديث
npm ls -g openclaw openclaw --version openclaw doctor

⚙️ تحديث الـ SDK (للمطورين)

إذا كنت مطور إضافات (plugin developer):

npm install openclaw/plugin-sdk@latest

استبدل أدوات infra-runtime القديمة بـ resolveExecModePolicy من execPolicy.
