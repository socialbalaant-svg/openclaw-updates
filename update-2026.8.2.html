🚀 أبرز المزايا الجديدة

  • Home Dock وكيل Home بجانب عملك: افتح Home في dock جانبي أو سفلي بـ Cmd/Ctrl+Shift+H مع إبقاء صفحتك الحالية ظاهرة، وإمكانية معاينة أو إزالة لقطة "Working on" أو إرفاق نص مختار للرسالة.
  • Linux Desktop رفيق سطح مكتب Linux: ثبّت .deb أو AppImage على Linux x86-64، واتصل بـ Gateway محلي أو بعيد، وافتح Quick Chat من System Tray أو اختصار X11. تحديثات AppImage موقّعة رقميًا.
  • Background Sessions بدء عمل بدون تبديل الصفحات: أنشئ وشغّل جلسة في الخلفية من New Session مع اختيار placement (محلي/سحابي/جهاز مقترن)، وافتحها من إشعار الاكتمال.
  • Safer Upgrades ترقيات أكثر أمانًا: الحفاظ على الإعدادات الأحدث، إيقاف ترحيلات الجلسات غير المكتملة قبل إعلان النجاح، واستعادة Gateway متوقف بعد فشل تحديث عند التحقق من سلامة الحزمة أو التراجع.
  • Voice Stability صوت أكثر موثوقية: إبقاء الاستدلال الداخلي خارج الكلام المنطوق، الحفاظ على الصوت المُولّد من الأدوات حتى التسليم، وضمان استمرار جولات Browser Talk بعد إعداد المكالمة.
  • Browser CDP تحكم المتصفح بدون Gateway: إيقاظ relay المحلي من إضافات Chrome على macOS وLinux المدعومة لعميل CDP مُصادَق، يحتاج تحديث native host وبناء إضافة يدعم wake-up.
  • 4 Themes أربعة أشكال جديدة: تخصيص Control UI بـ CRT أو Manuscript أو Rosé أو Miami، مع حفظ اختيار السمة أوفلاين وتطبيقها بدون وميض عند إعادة التحميل.
  • Replies Fix ردود تُنهي المهمة: إعادة الجواب النهائي بعد استقرار عمل الأدوات وعرض حالات الفشل بعد دور مقبول، لإصلاح المحادثات التي توقفت عند output الأدوات.

🛠️ التحسينات والتغييرات

  • Recovery تنظيف الاستعادة: معاينة أصول الترحيل المحفوظة بـ openclaw update cleanup --dry-run، ثم إزالة الأصول المؤهلة صراحةً أثناء توقف Gateway. يحافظ على سجل SQLite الحالي ويتنازل نهائيًا عن rollback.
  • Session Visibility رؤية الجلسات الافتراضية: السماح افتراضيًا للجلسات غير المعزولة بالعمل مع جلسات أخرى لنفس الوكيل (تشمل جلسات cron المحفوظة). عوامل التشغيل المشتركة يجب أن تضبط tools.sessions.visibility على tree أو self للحصر.
  • Cross-Session محادثات عبر الجلسات: عرض الرسائل المُعاد توجيهها كفقاعات مميزة مع روابط للجلسة المصدر وهوية الوكيل المرسِل، للحفاظ على الإسناد عند توجيه الرسائل لمحادثة نشطة.
  • Organization تنظيم الجلسات: تجميع إجراءات الجلسة في قوائم أوضح، نسخ النصوص كـ Markdown، فتح الجلسات في tabs أو نوافذ أو تقسيمات، تحرير الأيقونات والألوان معًا، وإخفاء مجموعات الجلسات الفارغة اختياريًا.
  • Cloud Projects مشاريع سحابية مُجهّزة: إعادة استخدام لقطعات المشاريع المُجهّزة والتحقق من hashes مساحات العمل قبل بدء جلسة سحابية، مع الحفاظ على دورة stop/snapshot/restart لمشاريع Daytona.
  • Beam Links روابط Beam قابلة للقراءة: مشاركة النصوص عبر روابط /beam/ مقسّاة على اسم الجلسة مع الحفاظ على فحوصات الوصول والتنقل السياقي.

📦 تعليمات التحديث

اتبع الخطوات التالية لتحديث OpenClaw إلى الإصدار الجديد:

  1. انسخ بياناتك احتياطيًا 
    cp -r ~/.openclaw ~/.openclaw.backup-$(date +%F)
  2. تحديث OpenClaw عالميًا 
    npm install -g openclaw@2026.8.2
  3. تأكيد نجاح التحديث 
    openclaw --version

    المتوقع: 2026.8.2

  4. إعادة تشغيل Gateway 
    openclaw gateway restart
  5. التحقق من سلامة البوابة 
    openclaw gateway status
⚠️ تنبيه: هذا إصدار رئيسي يحتوي على تغييرات في رؤية الجلسات الافتراضية (tools.sessions.visibility) وسلوك Home Dock. خذ نسخة احتياطية دائمًا قبل التحديث وراجع changelog الكامل للإعدادات التي قد تحتاج تعديل.
