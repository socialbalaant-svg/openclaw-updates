⚡ أبرز المميزات (Highlights)

  • استعادة استرجاع من تحديثات فاشلة متوافقة: الاحتفاظ بالحزمة السابقة واسترجاعها مع الإعداد والخدمة السابقين عند ثبوت سلامة الـ rollback من فحوصات الـ schema والتكوين. ترحيلات قواعد البيانات ما زالت تتطلب نسخة احتياطية مُتحققة قبل التحديث.
  • ورشة الإضافات الإضافات في مكان واحد: اكتشاف الإضافات المُدمجة و ClawHub، تثبيتها من Control UI، وإدارة إعدادها وإعداداتها وصلاحياتها في ورشة Plugins موحدة.
  • Cloud جلسات Cloud مُعدة: بدء جلسات Linux المؤهلة من مشاريع محلية مُعدة أو مستودعات GitHub عامة، وبناء snapshots قابلة لإعادة الاستخدام من Control UI قبل بدء المحادثة.
  • TUI الإجابة عن أسئلة في الترمينال: اختيارات بالكيبورد، إجابات نصية حرة، وأسئلة متعددة في كل من جلسات TUI المتصلة بالـ Gateway والمحلية.
  • نماذج GPT Image 2.5: طرازات جديدة Flare و Sunburst لتوليد وتعديل الصور عبر OpenAI أو fal دون تغيير طرازك الافتراضي الحالي.
  • تاريخ المحادثات سجل محادثات أكثر اعتماداً: استرجاع الردود النهائية بعد تدفقات منقطعة، الاحتفاظ بإشعارات المهلة بعد إعادة التحميل، ومنع تكرار الإجابات النهائية عند تسليم البث المباشر للسجل المحفوظ.
  • صوت صوت يُنهي العمل المُفوَّض: إعادة نتائج الـ Subagent إلى Talk وتسليم الإجابة النهائية حتى بعد جولات متعددة من التفويض.
  • إدارة التكوين تكوين مُدار خارجياً: تعيين OPENCLAW_CONFIG_READONLY=1 لمنع OpenClaw من إعادة كتابة التكوين المُدار مع الحفاظ على تشخيصات القراءة فقط وحالة الـ runtime العادية.

⚠️ تغييرات كاسرة (Breaking Changes)

🚨 Deprecation قادم في الـ SDK: agent-harness-credential-prompt-string-argument دخل حالة الإهمال بتاريخ 9 سبتمبر 2026؛ وسيظل الوسيط النصي التقليدي لـ buildCredentialSafetyPrompt مدعوماً حتى 30 نوفمبر 2026. على مطوري الإضافات تمرير { controlToolsAvailable }.
🚨 إزالة معلقة في توافقية الـ SDK: sdk-untrusted-context-identifier-aliases وصل تاريخ إزالة 8 سبتمبر 2026 لكنه ما زال removal-pending، تمديد فترة الانتظار حتى انتهاء ترحيل قراء الإضافات المنشورة.
  • استعادة الـ Rollback: حالات فشل التحديث المؤهلة بلا تغيير schema تستعيد الحزمة، command shim، الخدمة، وتكوين ما قبل التفعيل، ثم تتحقق من Gateway السابق. حالات فشل schema-تغيير، قواعد بيانات جديدة غير متوافقة، أو تعديلات المشغل في الفترة بينية تمنع الـ rollback التلقائي.
  • Cloud Ready Workers: جلسات Git المحلية المؤهلة و GitHub العامة يمكنها إعادة استخدام الـ workers المُعدة. جلسات المستودعات الخاصة والأجهزة المقترنة تبقى خارج هذا التدفق. إعداد افتراضي محجوز واحد لكل مشروع/بروفايل حتى 4 على مستوى Gateway — يتم محاسبتك عليها حتى تحذفها. عيّن cloudWorkers.profiles.*.readyWorkers إلى صفر لتعطيلها.
  • وضع القراءة فقط: OPENCLAW_CONFIG_READONLY=1 يُحترم عبر تكوين الكتابة والإعداد وإصلاحات Doctor وتغييرات الإضافات والتحديثات. لا يجعل حالة الـ runtime للقراءة فقط.

🔧 أهم التغييرات (Changes)

🛡️ الأمان والاستعادة

  • Rollback استعادة الحزمة، الأمر، الخدمة، وتكوين ما قبل التحديث المؤهلة عندما تتأكد سلامة schema والتكوين من التطابق.
  • Read-only منع OpenClaw من إعادة كتابة التكوين المُدار بالنشر (OPENCLAW_CONFIG_READONLY=1) مع الحفاظ على أوامر التشخيص.
  • رفع صلاحيات قريباً إنذار والترقية الإلزامية لـ Node.js عند عدم توافق runtime الـ CLI مع الحفاظ على التشخيص وأوامر التحديث للإصلاح.
  • Deepgram نسخ Deepgram Flux الجديدة: flux-general-en و flux-general-multi تتطلب ffmpeg مثبتاً.

🧩 الإضافات (Plugins)

  • Plugins تصفّح الإضافات المثبتة حسب الفئة، صفحات تفاصيل مُجمّعة، عناوين URL قصيرة مثل /reports، واكتشاف المهارات الإضافية المُدمجة و ClawHub من بحث واحد.
  • Cloud بناء، إعادة بناء، فحص، تثبيت، حذف، واستعادة snapshots لعمال Cloud المُدعومين من Settings → Connections → Cloud workers → Snapshots.
  • Cloud تعديل بروفايلات العمال المتقدمة والإعدادات الافتراضية للمستودعات، وفحص مواصفات آلة جلسات Cloud، واختيار عمّال Windows أصليين عند دعم الـ backend.

💬 المحادثات والـ TUI

  • TUI التنقل بين الاختيارات بالأسهم أو الأرقام، كتابة إجابة Other، تفعيل خيارات multi-select، وإعادة فتح سؤال معلّق بـ /question.
  • Chat شريط محادثات جانبي مدمج يساري مع هويات المرسل في معاينات المحادثات المشتركة، إضافة النص المحدد إلى composer الرئيسي، ومعاينة الفيديوهات قبل الإرسال.
  • الترميم التلقائي السماح لـ command reviewer التلقائي بقبول أو رفض أو تصعيد أمر ضمن سياق محادثة محدود مع احتفاظ سلطة الـ execution policy.
  • التعلم من المهارات فتح learning من العمل السابق في جلسة عادية يمكنك فحصها ومتابعة العمل فيها.

🧠 التشخيصات والذاكرة

  • Diagnostics التعرف على العمل الذي يحتجز قائمة انتظار دورة حياة الجلسة وعرض مرحلة تحضير تنظيف العناصر التي تستغرق وقتاً.
  • Memory استخدام طراز الـ embedding الخاص بالمزود الاحتياطي المختار وحالة الـ index، مراقبة الكتابات الخارجية في LanceDB، والاحتفاظ بالاستدعاء رغم انتهاء مهلة الـ trigger.

🐛 إصلاحات مهمة (Key Fixes)

  • 🔧 حدود الوصول والمحتوى: الحفاظ على allowlists مجموعات WhatsApp الحالية أثناء الإصلاحات الأمنية، استمرار حجب عناوين cloud-metadata عند تفعيل استثناءات IPv6 الخاصة، تحديد أحجام bodies لطلبات Slack HTTP، وحصر استرجاع اقتباسات Tlon على الـ post المُقتبَس.
  • 🔧 أمان الـ workspace والنسخ الاحتياطي: الحفاظ على تعديلات الـ workspace المتزامنة، تضمين ملفات التكوين الخارجية المطلوبة في النسخ الكاملة، إبقاء captures التحديث الخاصة خارج الصادرات العادية، وتحمل اختفاء sidecar SQLite مباشر بعد snapshot قاعدة البيانات.
  • 🔧 استعادة الترحيلات: استعادة تكوينات multi-agent بدون marker، إبقاء ترحيلات Skill Workshop الغامضة متاحة للمراجعة، شرح رفض ترحيل الجلسات المرتبطة بـ hard-link، والحفاظ على وسائط مُعَدَّلة عند إعادة نشر أرشيفات مُرحَّلة.
  • 🔧 Doctor والمصادقة: الحفاظ على حالة المصدر أثناء lint الكامل، محاذاة بروفايلات المصادقة المحفوظة أثناء الترحيل، تحديد رفض بروفايلات المصادقة القديمة على المزودين المتأثرين، استعادة رموز عقد legacy ذات scopes غير صالحة.
  • 🔧 تسليم الرد وتاريخ المحادثة: استرجاع الردود النهائية من تدفقات منقطعة وأخطاء أدوات سابقة، الاحتفاظ بنص الـ turn الفاشل الجزئي ونتائج المهلة، الحفاظ على حدود الفقرة والـ code-block، والإبلاغ عن ردود Responses مقتطعة على أنها غير مكتملة.
  • 🔧 استمرارية المحادثة: إبقاء الصور المرسلة مرئية أثناء تسليم التاريخ، منع وميض تبديل الجلسات الباردة، وتسوية تحديثات الجلسات المتزامنة بشكل متّسق.
  • 🔧 إعادة استخدام Claude CLI: إبقاء الجلسات الدافئة حية عند تغير استعداد skills-watcher دون تغير محتوى المهارات المُعدة، مع إبطال إعادة الاستخدام بعد تغير محتوى المهارات الحقيقي.
  • 🔧 المحادثات الصوتية: تسليم النتائج المُنتَجة والمفوَّضة بشكل متكرر، السماح باستشارات صوتية مستقلة من جلسات الطالبة مقفلة الطراز، وقطع الصوت الفوري المنقطع عند الكمية المُشَغَّلة فعلياً.
  • 🔧 Telegram: الاحتفاظ بالردود عند رفض HTTP proxy للنفق، التعرف على bot-ID mentions في النص وتعليقات الصور، الحفاظ على تباعد code-example، وإيقاف ردود فعل stall متأخرة بعد إلغاء التحضير.
  • 🔧 Discord: استعادة التفويض من رسائل guild، الحفاظ على نصوص voice-note ambient، عرض presence الأعضاء فور إعادة الاتصال، والاحتفاظ بـ captions و link emoji المتكررة.
  • 🔧 Slack: حل ملكية workspace للمؤسسات لـ heartbeat DMs، إبقاء ردود فعل التأكيد مستقلة عن ردود فعل الحالة، وتجنب تنسيق prose عادي ككود بعد مسارات Windows الجذرية.
  • 🔧 Mattermost و Signal: إبقاء حسابات Mattermost الشقيقة متصلة أثناء إعادة تحميل مراجع السر، الحفاظ على معاينات الاستبدال أثناء تراجع الرسائل السابقة، والاحتفاظ بـ Signal reply quotes عند فشل التسليم التدفقي.
  • 🔧 دقة نص القناة: الحفاظ على نصوص رسائل Matrix المجهولة و mentions المُهرَّبة، فك ترميز رسائل HTML-only Teams بشكل صحيح، الاحتفاظ بأنماط Feishu rich-text والأدوات غير المرتبطة، وإبقاء بادئات استجابة WhatsApp الصادرة خارج الرسائل الواردة.
  • 🔧 Android والشاشات القابلة للطي: انتظار المرفقات المختارة قبل إرسال تعليقاتها، استعادة نشاط أداة مكتمل، التمييز بين حالة الاتصال وجاهزية المحادثة، وإبقاء ضوابط التفكير والمهام background داخل ألواح الطي.
  • 🔧 اختيار المزود والطراز: الحفاظ على صفوف catalog مُؤلَّفة وهويات الطراز الدقيقة والبيانات الوصفية والاعتمادات عند تعايش الأسماء المستعارة أو تحديث الـ catalogs.
  • 🔧 استجابة Gateway: نقل تخطيط التاريخ البارد وفحوصات السلامة وتنظيف الأرشيف خارج الـ main thread؛ الحفاظ على التحديثات المُعدة وصيانة ما بعد الإخلاء استجابية؛ تقليل ارتفاع الذاكرة عند فحص جلسات طويلة.
  • 🔧 احتفاظ الجلسات: إيقاف التنظيف الزائد بعد زوال ضغط القرص، الحفاظ على التاريخ الذي يصبح محمياً أثناء التنظيف، وتجنب إعادة التعيين اليومية المبكرة حول فجوات التوقيت الصيفي.
  • 🔧 تثبيت الإضافات والمهارات: منع تطابق الإضافات المثبتة عبر registries ClawHub مختلفة، الإبلاغ عن إصدارات أحدث للتثبيتات المثبَّتة، استعادة dead-ends في موافقة القدرات، والاحتفاظ بثقة المُدمج لتثبيتات مسار التطوير.
  • 🔧 الأجهزة المقترنة و Linux: عرض window discovery على أول إجراء كمبيوتر، الحفاظ على نتائج التفعيل والملاحظة، فتح chat desktops على أجهزتها المعيّنة، وتحديد من أخذ التحكم في الـ desktop.
  • 🔧 Doctor وتثبيت التحديث: السماح بتفضيلات Codex ضمنية عند غياب الإضافة مع الاحتفاظ بأخطاء runtimes المطلوبة صراحةً؛ إنهاء تحديثات بلا تكوين دون إنشاء ملف تكوين.
  • 🔧 التفويض وإعادة التعيين: إبقاء wakes إكمال الخلفية حية بعد رد أمامي، الحفاظ على تاريخ الـ subagent عند تغير الـ parent thread، عرض نصوص subagent كاملة في task sidebar.
  • 🔧 توجيه المزود والبحث: الحفاظ على هويات توجيه مستقرة لدورات OpenCode و OpenCode Go المستقلة، الاحتفاظ بـ headers دورة المزود للجلسات الصريحة.
  • 🔧 ملكية التحديث واستمرارية Cloud: إيقاف استمرارية الإضافة وإجراءات rollback بعد فقدان صلاحية المُحدِّث، رفض استبدالات Gateway غير المُتحقَّق منها، الحفاظ على آلات Cloud عبر تحديثات Gateway.
  • 🔧 تشخيصات runtime والحالة: إعادة تنفيذ الـ CLI تحت runtime Node مدعوم متاح قبل رفض البدء، الحفاظ على مكتبة Bun SQLite المختارة في الخدمات المُدارة.
