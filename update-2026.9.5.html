🌟 أبرز الميزات في 2026.9.5

🦾 أكبر إصدار منذ آخر تحديث عندك: 4,179 Pull Request و 64 direct commit، شارك فيها 502 مساهمًا — التركيز على تحديثات آمنة بدون انقطاع، تكوين فريق من الوكلاء المتخصصين، GPT Live في الاجتماعات، أرشفة المحادثات، ومتصفح يعمل بالتوازي مع الوكيل.
⚛️ تحديثات ذرية (Atomic Updates) — تفحص الإصدار التالي قبل التحويل
  • أمان قبل القفز: قبل التبديل للإصدار الجديد على مسارات التحديث المدعومة، يفحص المُحدِّث الإصدار التالي للتأكد من جاهزيته.
  • تثبيت الإضافات بدون إعادة تشغيل البوابة: يمكنك تثبيت الإضافات (Plugins) أثناء عمل البوابة (Gateway) دون الحاجة لإعادة التشغيل.
  • إصلاح المشاكل القديمة عبر Doctor: المحادثات والبيانات الوصفية القديمة وسجلات الإقران وقوائم الرسائل الملفية تنتظر إصلاحًا صريحًا عبر openclaw doctor --fix بدلاً من إصلاحها تلقائيًا عند الإقلاع.
  • تحديثات الإضافات لا تعرقل الإصدار الأساسي: الإضافات غير المتوفرة لا توقف التحديث الأساسي بعد الآن.
👥 تكوين فريق من الوكلاء المتخصصين عند الإعداد
  • اختيار الأدوار: ابدأ بـ "رئيس فريق" + باحث + كاتب + مراجع، أو اختر وكيلًا واحدًا متخصصًا.
  • التعيين المُوجَّه: المعالج (Wizard) يمكنه إنشاء الفريق المكوَّن من 4 وكلاء، كما يقدّم وكيل جديد في واجهة الويب نفس الأدوار عبر اقتراح تحتاج للموافقة عليه قبل أي إنشاء.
  • استئناف آمن: يحفظ المعالج المنسق الذي اخترته لاستئناف العمل لاحقًا. اختيار Skip ينشئ الفريق دون اتصال، مع إمكانية ضبط الوصول للذكاء الاصطناعي لاحقًا.
  • صورة رمزية للوكيل: بعد الاتفاق على الاسم والشخصية، يقترح الإعداد 4 صور رمزية ويختار المستخدم المفضلة. تتطلب مزود صور متاحًا، ويمكنك التخطي والاكتفاء بالإيموجي.
🎤 GPT Live في اجتماعاتك ومكالماتك
  • يدعم OpenClaw الآن التفاعل الصوتي المباشر داخل الاجتماعات والمكالمات الهاتفية، مع إمكانية الفحص والتوجيه والإلغاء من واجهة الويب وDiscord.
  • تحسين معالجة wake-name — أكثر تحمّلًا للكلام البيئي بدون تشغيل عرضي للوكلاء.
  • تسجيل اجتماعات Discord: التقاط قائم على الإشغال (occupancy) في وضع الاستماع فقط، مع ملاحظات تلقائية وصفحة Meetings في Control UI.
🗄️ أرشفة المحادثات القديمة + تحكم في التخزين
  • ضغط المحادثات القديمة: ضغط المحادثات القديمة غير النشطة مع إبقائها متاحة لإعادة الفتح لاحقًا.
  • التخزين البارد (Cold Storage): معطل افتراضيًا. شغّله لأرشفة المحادثات المؤهلة بعد 30 يومًا، أو غيّر الفترة دون إعادة تشغيل.
  • تقرير التخزين في الإعدادات: يعرض كم التخزين الذي يستخدمه كل وكيل، مع زر Run now للأرشفة الفورية.
  • ترقية Schema 21: يرقّي قاعدة بيانات الوكلاء إلى schema 21 — الإصدارات الأقدم لا يمكنها فتحها. يجب عمل نسخة احتياطية قبل الترقية.
🧰 واجهة ويب جديدة كليًا + البحث في المحادثات
  • نظرة Agents overview: تجمع النشاط الأخير ومعاينات المحادثات في مكان واحد، مع رابط مباشر لكل محادثة رئيسية للوكيل.
  • اختيار أيقونة SVG مخصصة: الصق SVG مخصصًا في Icon & color → Custom icon… لمنح المحادثة صورة فريدة بها ألوانها.
  • إعادة ترتيب صفحات الإضافات في الشريط الجانبي: صفحات الإضافات تنضم لطلبك المحفوظ في الشريط الجانبي.
  • لوحة الأوامر مع بحث تدريجي: تعرض "Searching sessions…" أو "Searching commands…" أثناء البحث، مع الأوامر المحلية متاحة فورًا.
  • نشاط في علامة تبويب المتصفح: أيقونة التبويب تعرض عندما يعمل الوكيل، أو يحتاج موافقة، أو انتهى أثناء غيابك.
  • اختيار أين يبدأ عمل جديد: New Session يعرض أجهزتك في منتقي قابل للبحث، مع تفاصيل السعة وخيار Any available device.
  • المسودات والقائمة المنظَّمة: يمكنك إرسال نص ومرفقات أثناء تحميل السجل، وبدء المسودة التالية فورًا. التسليم ينتظر حتى تكون المحادثة جاهزة.
  • مسودات الفريق غير المرسلة: في الجلسات المشتركة، تظهر مسودة كل شخص في فقاعة ناعمة مكتوب عليها "Typing · not sent".
  • إدخال الإيموجي بالاسم: اكتب :smi في الشات لرؤية اقتراحات الإيموجي، ثم اختر بـ Arrow + Enter.
  • تعليقات على أجزاء الشات: اختر مقطعًا واختر Add to chat لحفظ تعليق دون إزعاج مسودة رسالتك.
  • الحفاظ على المشروع عند تفرع محادثة: Fork conversation و Fork from here يحافظان على المجلد/المشروع المحلي المختار.
🔧 تركيب وإعداد أكثر ذكاءً
  • اختيارات أقل للإعداد: الإعداد الجديد لـ OpenAI وChatGPT/Codex يبدأ بـ Astra إذا لم تختر نموذجًا أساسيًا.
  • إعداد محلي افتراضي Full Tools: الإعداد المحلي يختار Full tools افتراضيًا عندما لا توجد profile مضبوطة، بما في ذلك أدوات الرسائل والإضافات المفعّلة.
  • استعادة تثبيت سطر الأوامر: المثبّت يعيد استخدام Node وnvm المتوافقَين لديك دون تغيير ملف shell.
  • OpenClaw في حاوية Docker: sandbox shell وأدوات المتصفح ترى نفس ملفات workspace وskills حتى مع مسارات host مختلفة.
  • تثبيت CLI على FreeBSD: متاح الآن عبر install-cli.sh باستخدام Node وnpm النظاميين.
  • إعداد الجهاز بتوجيه أوضح: متصفح يستخدم device token يمكنه إعادة الاتصال بعد موافقة المدير.
  • الاحتفاظ بالوكيل الافتراضي بعد الترحيل: الإعدادات متعددة الوكلاء تحتفظ بالوكيل الافتراضي المحفوظ بعد إعادة التشغيل.
  • استئناف الإعداد المحلي المتقطع: الإعداد المتقطع يُكمل في الـworkspace الذي وافقت عليه، مع الاحتفاظ بالوكلاء والنموذج وruntime.

🔧 تعليمات التحديث

⚠️ قبل التحديث:
  1. حدّث Node.js إلى ≥ 24.16.0 (يفضّل 26.1.0+). التحديث من Node 22 أو 25 سيكسر SQLite.
  2. اعمل نسخة احتياطية كاملة من ~/.openclaw + قواعد البيانات قبل أي شيء.
  3. الإصدار 2026.9.5 يرقّي قاعدة البيانات إلى schema 21 — الإصدارات الأقدم لا يمكنها فتحها.
  4. إذا كنت على 2026.9.2، اتبع تعليمات schema-upgrade اليدوية.

1️⃣ التحقق من إصدار Node الحالي

node --version

يجب أن تكون النتيجة v24.16.0 أو أعلى (يفضّل v26.1.0+).

2️⃣ تحديث Node (إذا لزم) عبر nvm

nvm install 26
nvm use 26

3️⃣ التحديث العالمي (Global)

npm update -g openclaw

4️⃣ أو تثبيت إصدار محدد

npm install -g openclaw@2026.9.5

5️⃣ التحقق من الإصدار

openclaw --version
# يجب أن يطبع: 2026.9.5

6️⃣ إصلاح المشاكل القديمة (مهم بعد قفزة طويلة)

openclaw doctor --fix

7️⃣ إعادة تشغيل البوابة (Gateway)

openclaw gateway restart

8️⃣ فحص الحالة

openclaw status
