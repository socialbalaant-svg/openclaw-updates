  • تنظيف إلغاء تثبيت الإضافات: إزالة مسارات التثبيت المسجلة من plugins.load.paths.

📦 تعليمات التحديث

اتبع الخطوات التالية لتحديث OpenClaw إلى الإصدار الجديد:

  1. انسخ بياناتك احتياطيًا 
    cp -r ~/.openclaw ~/.openclaw.backup-$(date +%F)
  2. تحديث OpenClaw عالميًا 
    npm install -g openclaw@2026.7.1-2
  3. تأكيد نجاح التحديث 
    openclaw --version

    المتوقع: 2026.7.1-2

  4. إعادة تشغيل Gateway 
    openclaw gateway restart
  5. التحقق من سلامة البوابة 
    openclaw gateway status
⚠️ تنبيه: بعد التحديث قد تحتاج لإعادة ربط بعض القنوات (Discord/Slack/Telegram) إذا كانت الجلسات المحلية انتهت. خذ نسخة احتياطية دائمًا قبل أي تحديث رئيسي.
