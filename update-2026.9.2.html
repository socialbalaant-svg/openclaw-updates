🚀 أبرز المزايا الجديدة

  • أداء شات أسرع وأكثر استجابة: تحويل قراءة السجلات وتحضير النصوص الطويلة خارج حلقة أحداث البوابة، مع تحميل مباشر للوحات التحكم وتقليل أعمال التحميل المبدئي.
  • استعادة ترقيات واستعادة موثوقة: الحفاظ على الإعدادات النشطة والمهارات المفعّلة والوكيل الافتراضي أثناء التحديثات التلقائية، واستعادة إعادة تشغيل البوابة بعد تحديثات Git.
  • GPT-6 Astra دعم GPT-6 Astra: اختيار النموذج openai/gpt-6-astra عبر مفتاح OpenAI API أو حساب ChatGPT/Codex المؤهل، مع إدخال نص وصور واستدعاءات أدوات Responses.
  • إعادة تشغيل الردود تبقى بعد إعادة التشغيل: استعادة الردود النشطة والمدرّة والمفوّضة بعد إعادة تشغيل البوابة دون فقدان علامات الاسترداد.
  • نسخ احتياطي نسخ احتياطية تحفظ بياناتك: الحفاظ على النصوص الكاملة التي تحتوي على أحرف NUL مدمجة في نسخ Git الاحتياطية، ودعم تكوين Nix للروابط والإعدادات.
  • بدون إعادة تشغيل تغيير الإعدادات بدون إعادة تشغيل: تطبيق إعدادات الوكيل والنموذج والأداة والقناة والمتصفح والعقدة والوصول عبر أصحابها أثناء التشغيل.

🛠️ تحسينات إضافية

  • علامة الإضافات: ضع أيقونة الإضافة في assets/icon.png بدلًا من رابط manifest — تُحمَّل بدون طلب شبكة.
  • GPT-6 Astra Async Tools: تشغيل أدوات دالة مباشرة بشكل غير متزامن على مسارات Platform API، وتوجيه الردود النشطة عبر WebSockets المخزّنة مؤقتًا.
  • تسجيل دخول macOS عبر المتصفح: ربط البوابات المحفوظة عبر تسجيل الدخول الشخصي لـCloudflare Access، وفتح تطبيق Mac من موقع البوابة.
  • واجهة الإضافات التجريبية: من Settings → Labs → Custom plugin UI — يمكن للإضافات المساهمة بصفحات Control UI.
  • Apple Watch Talk التجريبي: Talk مستقل على Watch مع أدوات يملكها البوابة (يتطلب اتصال UDP).
  • ردود Slack الغنية: توجيه الوكلاء لاستخدام تخطيطات Block Kit المدعومة للردود الاستباقية.
  • Swarm مفعّل افتراضيًا: تنسيق وكلاء فرعيين متزامنين مع نتائج منظمة وتقدم مباشر.
  • صفحة الأجهزة: عرض أنواع الأجهزة ومقاييس الموارد وقدرات التوفر لسطح المكتب.

🔧 إصلاحات مهمة

  • أمان HTTP Proxy: تحديث اعتماديات HTTP والإبقاء على فحوصات DNS الوجهة فعّالة.
  • تنظيف الجلسات: الحفاظ على حالة الإضافات للوكلاء الآخرين عند حذف الجلسة، ومنع محاولات الإلغاء من حذف الحالة المستعادة.
  • Telegram Proxy Media: استرجاع الوسائط عبر وكلاء SOCKS المهيّأة صراحةً وطلبات HTTPS-proxy.
  • تنسيق تفاصيل Telegram: الحفاظ على العناوين والأكواد والاقتباسات والجداول داخل حاويات details عند الإرسال والتعديل.
  • الردود التلقائية: إبقاء اكتمالات automation وheartbeat مرفقة بمحادثتها وموضوعها الأصلي.
  • Slack: تجنب الردود المكررة بعد فقدان إقرارات البث، وإعادة محاولة رفض rate-limit الصريح.
  • WhatsApp: تسليم سبب فشل الدورة (فشل/مهلة/رفض) بدلًا من ترك المحادثة صامتة.
  • Cron Jobs: الحفاظ على الرد النهائي عند إزالة automation لنفسه، والحفاظ على سياسات تنبيهات الفشل.
  • تحديث OpenClaw: تقرير نجاح/فشل/تخطي قابل للتنفيذ من تحديثات chat-triggered.

📦 تعليمات التحديث

اتبع الخطوات التالية لتحديث OpenClaw إلى الإصدار الجديد:

  1. انسخ بياناتك احتياطيًا 
    cp -r ~/.openclaw ~/.openclaw.backup-$(date +%F)
  2. تحديث OpenClaw عالميًا 
    npm install -g openclaw@2026.9.2
  3. تأكيد نجاح التحديث 
    openclaw --version

    المتوقع: 2026.9.2

  4. إعادة تشغيل Gateway 
    openclaw gateway restart
  5. التحقق من سلامة البوابة 
    openclaw gateway status
  6. تشغيل التشخيص (موصى به) 
    openclaw doctor

    يتحقق من قاعدة بيانات SQLite والإعدادات والوكلاء.

⚠️ تنبيه: هذا تحديث رئيسي يقفز 4 إصدارات فرعية. تم تحسين آلية الاستعادة لمنع فقدان الإعدادات، لكن يفضل دائمًا أخذ نسخة احتياطية قبل التحديث.
🗑️ إيقاف قادم: سيُزال Plugin SDK context aliases (الأسماء غير الموثوقة) في أو بعد 8 سبتمبر 2026. يجب الترحيل إلى channel-named context fields و buildChannelMetadata.
